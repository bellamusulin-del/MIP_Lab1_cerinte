# MIP_Lab1_cerinte

Să se creeze o aplicație Windows Forms. 
Să se adauge patru butoane cu etichetele:
UP, DOWN, LEFT, RIGHT.
Să se adauge un TextBox și o etichetă (label).
La apăsarea fiecărui buton să se afișeze un mesaj (MessageBox.Show) diferit, cu seturi de butoane diferite (YesNo, RetryCancel, etc.) și cu pictograme diferite (Warning, Information, etc.).
Opțiunea selectată de utilizator (la cerința anterioară) să fie afișată în TextBox.
Să se adauge un Timer de o periodicitate de 300ms și alte două butoane etichetate cu START și STOP.
Timerul să fie pornit/oprit prin cele două butoane nou adăugate.
Timerul va modifica culoarea de fundal a ferestrei în mod aleator.
Să se adauge un nou TextBox și o etichetă.
În noul textbox se va introduce perioada de lansare a timerului.
Perioada se va modifica automat la modificarea conținutului TextBox (prin tratarea evenimentelor de modificare a conținutului).
Să se modifice poziția ferestrei pe ecran la apăsarea butoanelor UP, DOWN, LEFT, RIGHT.
Afișarea de mesaje și preluarea opțiunii utilizatorului
